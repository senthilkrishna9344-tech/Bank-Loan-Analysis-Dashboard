# 📊 Bank Loan Analysis Dashboard

## 📌 Project Overview
The Bank Loan Analysis Dashboard is an interactive Power BI project that analyzes loan data to provide insights into loan applications, funded amounts, repayments, borrower profiles, and loan performance. The dashboard helps identify lending trends and supports data-driven decision-making.

---

## 🎯 Objectives
- Analyze loan applications and funded amounts.
- Monitor total amount received from borrowers.
- Classify loans into Good Loans and Bad Loans.
- Analyze loan trends by month, state, purpose, employment length, and home ownership.
- Build an interactive dashboard for business insights.

---

## 🛠️ Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- CSV Dataset

---

## 📂 Dashboard Pages

### 1. Summary
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income (DTI)
- Good Loan vs Bad Loan Analysis
- Loan Status Summary

### 2. Overview
- Monthly Loan Application Trend
- State-wise Loan Analysis
- Loan Term Distribution
- Employee Length Analysis
- Loan Purpose Analysis
- Home Ownership Analysis

### 3. Details
- Complete Loan Records
- Interactive Filters and Slicers

---

## 📈 Key Insights
- Identified monthly loan application trends.
- Compared good and bad loan performance.
- Analyzed regional loan distribution.
- Identified the most common loan purposes.
- Examined borrower characteristics using employment length and home ownership.
